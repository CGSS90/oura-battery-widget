Privacy Policy

Oura Battery Widget is a personal, non-commercial project intended to display battery information from an Oura Ring.

The planned application will access ring configuration and battery information only with the account owner’s authorization. No analytics, advertising, or third-party data sharing is planned.

Authentication credentials and battery data are intended to remain on the owner’s device, not on this public website. The application is still under development; this policy will be updated if data handling changes.
